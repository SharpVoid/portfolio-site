## Новые экспорты / исходники

Размеры — ориентиры для Retina и читаемого просмотра, с сохранением пропорций. Увеличивать существующий растр нельзя. Для мелких подписей больше пикселей само по себе не увеличит текст на странице: нужен экспорт из исходных текстовых/векторных слоёв; для архитектуры и коллажей также нужны более крупные подписи либо отдельные читаемые фрагменты для последующего согласования.

## Доступные альтернативы и NDA

В репозитории более крупного эквивалента перечисленных проблемных материалов нет. Проверены другие активные и неиспользуемые project assets. Локальные резервные PNG тех же публичных файлов в work/media-optimization/originals имеют то же intrinsic-разрешение; они не решают нехватку пикселей и мелкую композицию.

FocusML structure/interface/team/result имеют разрешение 3219 × 2467, 10290 × 6540, 1722 × 1265 и 6140 × 6909. Размытые и скрытые материалы уже обезличены по NDA. Новые открытые версии не нужны и не запрашиваются. Мелкие подписи в общих коллажах удобнее читать через существующий preview; увеличивать разрешение этих файлов ради снятия blur бессмысленно.
